# Linear풍 비주얼 개선 — 틀 전체 + 보드 집중

2026-10-12 · 승인됨

## 목표

«디자인이 구리다»는 피드백의 원인은 개별 화면보다 **틀**에 있다 — 검은 사이드바,
같은 무게의 텍스트 버튼 7개가 늘어선 헤더, 회색 배경 + 카드 박스 구조, 회색 칩,
12~13px 단일 크기 텍스트. 이를 Linear풍(무채색 + 포인트 1색, 정돈된 밀도)으로 바꾸고,
가장 오래 보는 **보드**를 새로 설계한다.

범위: 디자인 토큰 · 사이드바 · 헤더 · 보드 뷰 전면.
범위 밖: 요약·목록·캘린더·메모·프로젝트 뷰와 모달의 재설계(토큰 효과 + 깨지는 곳 보정만),
등록 입구 개선(AI 초안 입력 — 별도 설계로 이어 간다), 기능 변경 일체.

## 선택한 접근 (A안)

틀(토큰·사이드바·헤더) 전면 교체 + 보드 재설계. 틀을 바꾸면 모든 화면이 한 번에 올라가고,
남은 힘을 실사용 1순위 화면에 쓴다.

기각안: B안(보드만 — 한 화면만 톤이 달라져 일관성 붕괴), C안(전 화면 전면 — 범위가 커서
한 번에 하기엔 위험, 필요하면 이 작업 이후 뷰별로 이어 간다).

## 1. 토큰 (`public/style.css` `:root`)

| 토큰 | 라이트 | 다크 | 비고 |
|---|---|---|---|
| `--bg` (본문 면) | `#FFFFFF` | `#16191E` | 회색 앱 배경 폐지 — 본문은 한 장의 면 |
| `--surface` (카드·모달) | `#FFFFFF` | `#16191E` | **변경 금지** — 팔레트 3:1이 이 값 기준 |
| `--side-bg` | `#F7F8FA` | `#0F1115` | 검은 사이드바 폐지, 본문과 한 톤 차이 |
| `--accent` | `#5E6AD2` | `#8B93F5` | 인디고. 텍스트 대비 4.70 / 6.37 |
| `--accent-h` | `#4F5AC0` | `#A5ACF8` | hover |
| `--accent-bg` | `#EEF0FB` | `#1E2140` | 드롭 대상·선택 배경 |

- 사이드바 전용 `--side-fg/dim/hover/line`은 일반 토큰(`--text-2`, `--text-4`, `--hover`, `--line`)으로
  흡수한다. 사이드바가 더 이상 «어두운 면»이 아니기 때문.
- 토스트(`--inv-bg`)는 어두운 면 유지.
- 사이드바 분류 점은 `#F7F8FA` 위에서 팔레트 최저 2.92:1로 3:1에 약간 못 미친다. 점 옆에 분류 이름이
  항상 붙어 있어 점이 유일한 정보 전달 수단이 아니므로(WCAG 1.4.11 비해당) 허용한다.

### 타이포 3단계

| 용도 | 크기/굵기 | 색 |
|---|---|---|
| 섹션·열 제목, 뷰 제목 | 13px / 600 | `--text` |
| 태스크 제목·본문 | 13px / 500 | `--text` |
| 메타(마감·분류·개수) | 12px / 400 | `--text-3` |

### 칩

분류·상태 칩은 **색 점(7px) + 텍스트**, 배경 없음. `.tint` 배경 칩은 보드 카드에서 제거하고,
다른 뷰는 토큰 효과만 받는다(목록의 상태 칩 등은 이번 범위에서 유지).

## 2. 사이드바

- 폭 232 → 220px. 브랜드는 `MyWork` 13px/600 한 줄(부제 `개인 업무 관리 · 박진혁` 제거).
- 메뉴 항목: 인라인 SVG 아이콘(16px, 외부 라이브러리 없음) + 라벨 + 개수. 활성은 `--hover` 배경만, 왼쪽 막대(`.mark`) 제거.
- 분류 섹션: 점 + 이름 + 개수, 간격 축소. 제목 `업무분류`는 12px `--text-4`.

## 3. 헤더

- 높이 56 → 48px. 왼쪽 뷰 제목에서 «뷰» 접미사 제거(«보드 뷰» → «보드», 모든 뷰 공통).
- 오른쪽: 검색 입력 · 분류 select · **아이콘 버튼 묶음**(완료 숨김 · 정리 · 설정 · AI 지시) · `+ 새 태스크`.
- 아이콘 버튼은 텍스트 라벨 대신 인라인 SVG + `title`·`aria-label`. `완료 숨김`의 켜짐 상태는 `--accent-bg` 배경 + `--accent` 아이콘색.
- **기존 `id`(`q`, `f-category`, `hide-done`, `open-archive`, `open-settings`, `open-ai`, `new-task`, `show-arch-notes`)는 그대로 둔다** — 이벤트 바인딩과 단축키가 이 id에 걸려 있다.
- 6개 HTML 파일의 헤더 마크업을 같은 구조로 교체한다.

## 4. 보드

### 열
- 열 배경·테두리 제거(투명). 폭 **272px 고정**, 넘치면 보드가 가로 스크롤. 열 간격 16px.
- 열 머리: 상태 색 점 + 이름(13/600) + 개수(12, `--text-3`) + 오른쪽 `+` 아이콘 버튼(빠른 추가).
  `⠿` 그립은 hover 시에만 보인다. 열 순서 드래그는 머리 전체에서 그대로.
- 하단 점선 `＋ 태스크 추가` 버튼 제거. 빠른 추가 입력은 `+`를 누르면 **열 맨 위**에 뜬다
  (Enter 연속 추가 · Esc/바깥 클릭 저장 규칙 동일, `data-act="bq-open"` 유지).
- 빈 열: `비어 있음` 12px `--text-4` + 최소 높이 120px 유지(드롭 대상).
- 드래그 중 드롭 대상 열: `--accent-bg` 배경, 열 순서 드래그의 좌우 삽입선은 유지.

### 카드
- 테두리 1px `--line`, 반경 6px, 그림자 없음. hover 시 테두리 `--icon`(액센트 아님 — 차분하게).
- 패딩 10px 12px, 내부 간격 6px.
- 1행: 제목 13/500, 최대 3줄 말줄임.
- 2행 메타 한 줄(12px `--text-3`): `● 분류` · `☑ 0/3`(체크리스트) · `하위 1/3` · 반복 아이콘 · 오른쪽 끝 마감.
  - 마감 표기: 지연 `N일 지연`(`--danger`), 오늘 `오늘`(`--warn`), 대기 `MM/DD 대기`(`--text-4`), 나머지 `MM/DD`, 없음은 생략.
    기존 `dueMeta()`의 `short`·`color`를 그대로 쓴다.
- 하위 태스크 카드: 제목 위 `↳ 상위 제목` 한 줄(11.5px `--text-4`), 왼쪽 컬러 막대 제거.
- 완료 열 카드: `opacity:.6`, 제목 취소선 유지.
- 체크리스트 진척 막대(`.prog-row`)는 카드에서 제거하고 메타의 `0/3`로 대체.

## 5. 다른 뷰 · 모달

- 회색 앱 배경이 사라지므로 `.card` 박스가 흰 면 위 흰 박스가 된다 — 테두리만 남는 형태로 자연스럽게 보이는지
  확인하고, 겹쳐 보이는 곳만 보정한다.
- 모달·토스트·포커스 링·모션·`inert` 처리는 손대지 않는다.

## 6. 불변 조건

- 모든 `data-act`, `data-id`, `data-drop`, `data-opt`, 요소 `id` 유지 — 동작·테스트 무변경.
- `light-dark()` 단일 토큰 체계 유지(미디어쿼리 두 벌 금지).
- 반응형 브레이크포인트(1100 / 960 / 560px) 동작 유지. 960px 이하 사이드바 가로 바 전환도 새 톤으로.
- 새 의존성 없음. 아이콘은 인라인 SVG.

## 7. 검증

- `npm test` 전부 통과(동작 무변경 확인).
- 대비: 액센트 텍스트 4.5:1, 팔레트 vs 카드면 3:1을 스크립트로 재계산.
- 스크린샷: 요약·목록·보드·캘린더·메모 × 라이트/다크, 보드는 960px·560px 추가. 드래그·빠른 추가 수동 확인.
