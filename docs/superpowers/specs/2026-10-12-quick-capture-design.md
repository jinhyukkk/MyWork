# 빠른 입력 바 — 한 줄로 태스크 등록

2026-10-12 · 승인됨

## 목표

등록할 때 가장 흔한 상황은 «한 줄로 빨리 적기»다(«금요일까지 인사시스템 발령 에러 확인»).
지금은 `n`이 전체 모달을 열어 제목·상태·분류·마감을 손으로 채워야 한다.
한 줄을 치고 Enter를 누르면 마감과 분류가 채워진 태스크가 **즉시** 생기게 한다.

범위: `n` 키·`＋ 새 태스크` 버튼의 동작, 한 줄 해석기, 저장 직후 토스트.
범위 밖: 서버·스키마 변경, AI 지시창(`i`), 보드 열 `+` 빠른 추가, 여러 건 한 번에 등록.

## 선택한 접근 — A. 로컬 규칙 파서

한 줄에 들어오는 날짜 표현은 «금요일까지», «내일», «10/20» 정도라 규칙으로 충분하다.
결과가 즉시 나오고 API 키·비용이 없으며 단위 테스트로 고정할 수 있다.

기각안:
- B. Claude 해석 — Enter마다 2~5초를 기다려야 해 «빨리»와 정면으로 충돌한다.
- C. 혼합 — 입구가 두 갈래가 된다. 긴 문장은 이미 AI 지시창이 받는다.

## 1. 빠른 입력 바

- `n` 또는 헤더의 `＋ 새 태스크`를 누르면 화면 상단 중앙(위에서 12vh)에 입력 바가 뜬다.
  흰 알약 모양 판에 `--elev-lg`를 쓰고, 폭은 `min(560px, 100vw - 24px)`. 배경 딤은 없다 — 모달이 아니다.
- placeholder: `할 일 한 줄 — 예: 금요일까지 #인사시스템 발령 에러 확인`
- 입력하는 동안 바 아래에 **해석 결과 칩**을 실시간으로 그린다. 확인 단계가 아니라 «이렇게 들어간다»를 보여 주는 표시다.
  - `📅 10/16 (금)` — 마감이 잡혔을 때만
  - `● 인사시스템` — 분류 알약(`.chip.tint`, 분류색). 분류를 못 찾았으면 기본 분류를 흐리게(`opacity:.6`) 보여 준다
  - 제목이 비면 칩도 그리지 않는다
- 키:
  - `Enter` — 즉시 저장하고, 입력창을 비운 채 바를 유지한다(연속 입력).
  - `Shift+Enter` — 해석 결과를 채운 **전체 모달**을 연다(`openNew` 경로 + 제목·분류·마감 주입). 바는 닫는다.
  - `Esc`·바깥 클릭 — 바를 닫는다. **내용이 있으면 저장한다** — 보드 빠른 추가·메모 빠른 작성과 같은 규칙. 비어 있으면 그냥 닫힌다.
- `n` 단축키의 무시 조건(입력 중·모달 열림)은 기존 그대로다. 바가 열려 있는 동안 `/`·`n`·`i`는 무시한다.
- 입력값은 매 렌더에 innerHTML로 새로 그려지므로, 입력 이벤트는 재렌더 없이 **칩 영역만** 갱신한다(커서·IME 조합이 깨지지 않게).

## 2. 해석 규칙 — `public/quickparse.js`

순수 함수 `parseQuick(text, { today, categories })` → `{ title, due, category }`.
`today`는 `YYYY-MM-DD`, `categories`는 설정 순서의 분류 이름 배열이다. `due`·`category`는 못 찾으면 `null`.

| 입력 | 결과 | 제목에서 |
|---|---|---|
| `오늘` `내일` `모레` | today / +1 / +2 | 제거 |
| `월`~`일`, `월요일`~`일요일` (단독 토큰) | 다가오는 그 요일. 오늘이 그 요일이면 오늘 | 제거 |
| `이번주 금`, `이번 주 금요일` | 이번 주(월~일) 그 요일. 이미 지났으면 다가오는 그 요일 | 제거 |
| `다음주 월`, `다음 주 월요일` | 다음 주(월~일) 그 요일 | 제거 |
| `10/20`, `10.20`, `10월 20일` | 그해 그 날짜. 오늘보다 앞이면 다음 해 | 제거 |
| `20일` | 이번 달 20일. 오늘보다 앞이면 다음 달 | 제거 |
| 날짜 표현 바로 뒤의 `까지`·`까지는`·`전까지` | 무시 | 제거 |
| `#분류이름` (대소문자 무시, 설정에 있는 이름) | 분류 지정 | 제거 |
| 분류 이름이 그대로 포함됨 | 분류 지정 | **유지** — 문장의 일부일 수 있다 |

- 여러 날짜 표현이 있으면 **첫 번째**만 쓰고 나머지는 제목에 남긴다.
- `#분류`가 있으면 포함 매칭보다 우선한다. 포함 매칭은 **가장 긴 이름**이 이긴다(`유진GPT`와 `GPT`가 둘 다 있으면 `유진GPT`).
- 단독 요일 토큰(`월`, `금` 등 한 글자)은 공백 경계에 있을 때만 날짜로 본다 — `금요일`이 아닌 `금액` 같은 단어를 잡지 않게.
  `일`은 «일요일»로 보지 않는다(«일 정리» 같은 오탐이 잦다). `일요일`만 인정한다.
- 존재하지 않는 날짜(`2/30`)는 날짜로 보지 않고 제목에 남긴다.
- 제거 후 남은 공백은 하나로 줄이고 양끝을 자른다. 제목이 비면 저장하지 않는다.

## 3. 저장

- `POST /api/tasks` 바디: `{ title, status: firstOpen(), category, start: TODAY, due, memo: '', repeat_days: 0, parent_id: null }`.
- 분류 우선순위: 해석 결과 → 사이드바 분류 필터(`S.fCategory`) → 첫 분류(`S.categories[0]`). 보드 빠른 추가와 같은 기본값이다.
- `start: TODAY`는 파서가 오늘 이전 날짜를 내지 않으므로 «시작일 ≤ 마감일» 검증에 걸리지 않는다.
- 실패하면 바 아래에 서버 에러 문구(`.err`)를 보여 주고 입력값을 유지한다.

## 4. 저장 직후 토스트

- 토스트 ««제목» 추가됨» + 버튼 `수정` · `되돌리기`. 5초 뒤 사라진다.
- `수정` — 그 태스크의 편집 모달을 연다(`openTask`). 빠른 입력 바는 닫는다.
- `되돌리기` — 방금 만든 태스크를 곧바로 `DELETE` 한다(막 생긴 건이라 체크리스트 CASCADE가 없다).
- 토스트는 하나뿐이다. 지연 확정(삭제·완료) 대기 건이 있으면 그 토스트가 우선이고, 추가 알림은 대기 건이 없을 때만 보인다.
  새 추가 알림은 이전 추가 알림을 대체한다.

## 5. 바뀌지 않는 것

- 서버·스키마·REST 무변경. 기존 모달(`openNew`)은 `Shift+Enter`와 다른 입구(하위 태스크 추가 등)에서 그대로 쓴다.
- 보드 열 `+`, 프로젝트 하위 추가, 메모 → 태스크 전환, AI 지시창 무변경.
- 단축키 `/`, `i`, `Ctrl+Enter` 유지. 모든 기존 `id`·`data-act` 유지(`new-task` 버튼 id 유지, 동작만 바뀜).
